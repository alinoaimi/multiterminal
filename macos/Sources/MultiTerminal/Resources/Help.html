MultiTerminal Help

Build your workspace

  1. Choose New Workspace in the toolbar, or press Shift–Command–N.
  2. Use the + menu to add a terminal, browser, or read-only file preview. Browsers accept HTTPS, HTTP, and localhost addresses.
  3. Drag a pane tab to an edge to split the layout, or to the center of another group to combine tabs. Drag a divider to resize.
  4. Use the workspace menus to rename, close, reopen, or delete workspaces. Layouts, folders, files, URLs, and themes are saved. Reopened terminals start fresh shells.

Files and browsers

Preview Markdown, text, images, PDFs, and other supported files without editing. Previews refresh when files change on disk.

Browser panes share website data within one workspace and use separate profiles across workspaces. Closing retains that profile; deleting the workspace removes it. File previews use temporary web storage.

Your tools

Install and configure command-line tools separately. Commands run with your macOS user's permissions. External tools and websites have their own accounts, costs, and privacy policies.
