MultiTerminal Privacy

Local workspace data

Workspace names, layouts, folders, file paths, browser URLs, and themes are saved on your Mac in ~/Library/Application Support/MultiTerminal Source/workspaces.json. Treat that file and recovery backups as private. Terminal output is not saved by the app, but your shell and commands may write their own history or logs.

Browser and preview data

Browser panes use WebKit and store cookies, caches, and other website data locally in a separate profile for each workspace. Closing a workspace retains this data; deleting it requests removal. File previews read files you select and use temporary web storage.

Network access

This source build has no usage reporting or automatic update service. Browser panes contact sites you open, and commands you run may contact external services. Those services receive ordinary connection information and have their own privacy policies.
